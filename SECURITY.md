# Security

Please report a suspected security or privacy problem privately through GitHub's security-advisory feature instead of opening a public issue.

The installer reads and updates a local Stream Deck XL profile. It does not use the network, collect analytics, or transmit profile data. A complete timestamped backup is created before installation.

Do not attach a live Stream Deck profile to a public issue because it may contain device identifiers, personal paths, addresses, or other configuration.
