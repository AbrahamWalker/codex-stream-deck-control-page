# Support

Use GitHub Issues for reproducible installation problems, incorrect labels, and shortcut changes.

Include:

- Windows version
- Stream Deck software version
- Codex app version
- Stream Deck model
- The exact installer error

Do not upload a live Stream Deck profile, backup, recording, credential, device identifier, or private file path.

This community project is provided without guaranteed response times or official OpenAI or Elgato support.
